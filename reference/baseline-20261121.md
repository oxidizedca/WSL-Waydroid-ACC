# 2026-11-21 部署基线

[English](#english)

以现场安装件为准，而不以最近一次编译为准。固化时，WSL 中运行的 Weston、input-broker 和 texture-consumer 的进程映射均指向 `/usr/local/lib/wsl-waydroid-acc/releases/built.0L1nxt11`。此名称只标识该机器的一次安装；在别处恢复时会生成新目录名。

| 恢复范围 | 已核对的内容 |
| --- | --- |
| Android | EGL/GLES shim、Gallium、HWC、快速 PNG 编码器；对照已挂载的 Waydroid 根文件系统和容器数据目录。 |
| WSL 宿主 | 输入 broker、纹理 consumer、虚拟触屏、libweston、GL 渲染器和 Wayland 后端；另对照安装目录的 EGL、Gallium 与 [host 清单](../host/SHA256SUMS)。 |
| 部署配套 | 启动/等待/触屏脚本、截图入口、Weston 配置、视频 init、tmpfiles 配置、4 个 systemd 服务及 1 个 drop-in。冻结副本及全部 11 个二进制均列入 [runtime 清单](../runtime/SHA256SUMS)。 |

**二进制来源。** 基线使用实机安装件，输入 broker 的 SHA-256 以 `f080048f14bb` 开头。核验部署内容请用清单，不以 `out/` 的时间戳或临时构建目录名判断。

**保留的行为。** 默认自由窗口、无 Weston 顶栏、1920×1080；支持固定窗口和保持比例。保留虚拟多点触控、启动时按需建立的本机 ADB 转发、无损 PNG 截图及加载器的共享页和暂存槽优化。镜像、用户数据、外部转译层及 KernelSU 模块不是此加速层基线包的内容；没有把 CPU/GPU 调度实验变成启动参数或模块。

从仓库根目录可先只读核验，再按需恢复：

```sh
(cd runtime && sha256sum --strict --quiet -c SHA256SUMS)
(cd host && sha256sum --strict --quiet -c SHA256SUMS)
# 仅在需要恢复时执行：会重启容器和嵌套 Weston。
sudo bash deploy.sh restore
```

`apply`（默认）和 `restore` 使用冻结的二进制与 `runtime/services/`；`built` 使用 `out/` 和开发树的 `services/`。三者安装同一组组件。恢复的是加速层，不是整机快照；前置环境见[构建和部署说明](../README.md#43-编译离屏验证与部署)。

# Deployment baseline: 2026-11-21

The baseline uses installed files, not the most recent build. At freeze time Weston, input-broker and texture-consumer all mapped `/usr/local/lib/wsl-waydroid-acc/releases/built.0L1nxt11`. This name identifies one installation on this machine; restoring elsewhere creates a new release directory name.

| Restore scope | Verified contents |
| --- | --- |
| Android | EGL/GLES shims, Gallium, HWC and fast PNG encoder, checked against the mounted Waydroid root and container data. |
| WSL host | Input broker, texture consumer, virtual touch, libweston, GL renderer and Wayland backend; installed EGL and Gallium checked against the [host manifest](../host/SHA256SUMS). |
| Deployment support | Startup, wait and touch scripts; screenshot entry point; Weston config; video init; tmpfiles; 4 systemd services and 1 drop-in. Frozen copies and all 11 binaries are in the [runtime manifest](../runtime/SHA256SUMS). |

**Binary provenance.** The input broker in the installed baseline has a SHA-256 beginning `f080048f14bb`. Verify deployments against manifests, not `out/` timestamps or temporary build names.

**Retained behavior.** By default the window is freely resizable at 1920×1080 with no Weston top panel; fixed and aspect-fit modes are available. The baseline keeps virtual multitouch, on-demand loopback ADB forwarding at startup, lossless PNG capture, shared loader pages and staging-slot reuse. It does not include the OS image, user data, an external translator or KernelSU modules, or turn CPU/GPU scheduling experiments into startup options or modules.

From repository root, verify read-only first, then restore only if needed:

```sh
(cd runtime && sha256sum --strict --quiet -c SHA256SUMS)
(cd host && sha256sum --strict --quiet -c SHA256SUMS)
# Run only if restoring: this restarts the container and nested Weston.
sudo bash deploy.sh restore
```

`apply` (default) and `restore` use frozen binaries and `runtime/services/`; `built` uses `out/` and the development `services/`. All install the same component set. This restores the graphics layer, not the entire machine. See [Build and deployment](../README.en.md#43-build-offscreen-validation-and-deployment) for prerequisites.
